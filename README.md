# 摸鱼事务所 · 下班前的九十秒

基于 [写实交互设计文档](docs/2026-09-07-game-office-realistic-design.md) 的第一人称工位 H5 样板。直接操作电脑、手机和杯子，坐在工位连续转头环顾办公室，通过经理和同事的方位、距离判断动静，在工作与休息之间留出收尾时间。

在线体验：https://coffeeeeffoc.github.io/office-slacking/

## 启动

已使用 Node.js 24.12.0 验证。唯一 npm 运行依赖为固定版本的 **Three.js 0.180.0**；首次启动需要安装锁定依赖。浏览器必须支持 **WebGL2**。

Windows PowerShell：

```powershell
Set-Location 'F:\playground\playground-ai\office-slacking'
npm ci
npm run dev
```

浏览器打开 <http://localhost:5173>。按 `Ctrl+C` 停止服务。端口被占用时可先执行 `$env:PORT = '5174'`，再启动服务并访问相应端口。

```powershell
npm test          # 规则、路线、骨骼接地与桌面交互回归
npm run check    # JavaScript 语法检查
npm run build    # 生成 dist 静态文件
npm run preview  # 从 dist 启动本地预览，默认端口同为 5173
```

开发服务与预览服务默认使用同一端口，切换前先停止前一个服务。

## 怎么玩

一局 90 秒，两项目标：核对并保存回款合计 **128,600 元**；积累至少 **20 秒**个人休息。结束时还要收好手机、切回工作表，并且没有被明确识破。

| 对象 | 操作 |
| --- | --- |
| 环顾 | 拖动场景空白处连续转头；手机上横向轻划。← / → 或 A / D 左右转头，↑ / ↓ 调整俯仰；也可用顶部方向按钮或角度滑杆 |
| 人物 | 经理与小林的箭头显示相对方位，米数显示场景内地面距离；点击距离按钮看向人物，进入视野后可看到人物、距离和当前活动 |
| 回工位 | 点击中央朝向文字或按 Home 回正视线；按 Space 回到工位并切回工作表 |
| 工作表 | 修改合计，点击“核对并保存”；在输入框按 Enter 也可保存 |
| 电脑 | 点击“窗外”开始放空；点击工作标签或按 Space 回到表格 |
| 手机 | 点击或按 P 拿起/收好；拿起后向上划翻消息，向下划或拖向抽屉收好 |
| 收尾 | 也可直接点“收好手机”或抽屉，拖动不是必需操作 |
| 杯子 | 点击“喝口水”或按 C，正常饮水不增加疑心，整局最多贡献 4 秒休息 |
| 经理问话 | 点击回答；答错可以重答，也可请求一次澄清来延长等待 |
| 暂停 | 按 Esc 或点暂停；切到其他窗口或后台时自动暂停，回来后手动继续 |
| 声音 | 开始上班时启用环境音；顶部按钮可关闭，静音仍有完整来路和问话提示 |

普通按钮可用 Tab 聚焦、Enter 或 Space 激活；按钮聚焦时，Space 优先激活该按钮。金额输入期间，游戏快捷键让位给文本输入。

手机拿起约 0.65 秒，正常收好约 0.75 秒，中途可以改变主意。切换电脑不会收走手里的手机，收手机也不会关闭休闲页面；当前关注的娱乐内容才积累休息时间，两块屏幕不会叠加计分。经理有两条带预警的巡查路线，短暂一瞥只积累疑心，及时处理证据后仍能继续。

转身观察不会暂停倒计时或人物行动。视线离开工位后，手机消息与电脑风景页暂停积累休息时间；饮水仍按原规则计分。转头不会消除手机亮屏或电脑休闲页面留下的证据：经理靠近时照样能发现。手机仍在手里时，画面下方会出现独立的“点此收好”按钮，无需先转回工位。

## 静态交付

`npm ci` 的安装后脚本会从本地 `node_modules` 复制 Three.js 及所需附属模块到 `public/vendor/three/`；页面通过 import map 引用这些本地文件。`npm run build` 刷新本地依赖副本并复制运行所需文件到 `dist`：

```text
dist/
  index.html
  src/             # 界面、规则、空间路线、实体房间、人物与桌面渲染
  public/assets/   # 本地人物 GLB、图片和素材许可
  public/vendor/   # Three.js 与实际使用的附属模块
```

将 **dist 内的内容**放在静态服务器的站点目录。资源使用相对 URL，支持根目录和 GitHub Pages 仓库子路径。推送到 `main` 后，GitHub Actions 自动运行测试、构建并部署 `dist` 到 GitHub Pages。请通过 HTTP 服务访问，不要双击 `index.html` 以 `file://` 方式运行。构建产物不需要后端或 JavaScript CDN。游戏没有账号或存档，刷新会重开。

## 空间与人物

办公室现在由实体地面、桌椅、柜子和通道构成，`src/layout.js` 同时供房间渲染与人物路线使用。经理先停步、原地转身再走，人物身体朝向不随玩家镜头转动；人物沿通道绕过家具，起步和收步有加减速。`src/people.js` 使用带骨骼的 GLB 人物，行走动画按累计路程与模型步幅推进，并校正鞋底接地，避免身体始终朝向玩家或整个人在地面上漂移。

`src/room.js` 提供实体场景，`src/desk.js` 将可操作的电脑、手机界面用 CSS3D 放到同一相机和实体底座上。手机放下时落在桌面，拿起后随玩家视线移动，转身仍可收好；电脑保持在工位。拖动场景和装饰文字不会触发文字选中，金额输入框仍可正常选取和编辑。

六名同事常驻工位，打字与看屏幕按错开的节奏交替，个别同事偶尔伸懒腰、转头看窗外；小林多数时间坐着办公，一趟离座顺路打印、接水、饮水和短暂交谈，再带着杯子与打印稿回座。椅面、键盘、手部和人物位置共享坐标，起坐采用骨骼动画。

水杯改为空心杯壳与内壁，水面低于杯口，消除转头时杯顶与水面共面造成的闪烁。声音使用本地录制的键盘、脚步、滚椅、饮水、接水和打印片段，按人物动作触发、距离衰减和视角声向混合；空调为轻量合成底噪，交谈使用模糊人声环境音。具体台词仍由文字呈现。素材来源和座椅声音署名见 [音效许可](public/assets/audio/LICENSE.md)。

人物模型来自 Quaternius，采用 CC0 许可，具体来源和原始文件记录见 [模型许可](public/assets/models/LICENSE.md)。这是简化材质与造型的三维办公室，并非照片级写实；当前仍是坐在工位环顾，不能自由走动。CSS3D 页面不能与所有三维网格自动逐像素遮挡，当前通过朝向裁剪与物体正面布局控制显示范围。

## 验证与当前边界

本次 `npm test` **24/24**、语法检查和静态构建通过，覆盖：

- 原有独立证据、连续收放、暂停、可补救问答、胜负条件、两条路线可通关与 30/60 fps 时间步等价。
- 四向与俯仰投影、角度回绕、人物距离、全局时间驱动的连续路线；对两条路线按 0.01 秒采样检查脚底高度、家具碰撞、通道边界、渐变转向和移动方向。
- 实际 GLB 骨骼姿态、转身、鞋底接地、支撑步滑移、坐姿与手部接触以及暂停冻结。
- 多人工位布局、小林日程和道具交接；声音按动作启停、按行程落脚、镜头声像、暂停和静音后不补播。
- 手机接触桌面、拿起中途反向、手持随头转动、放回原处，以及桌面渲染重建后的节点、输入和事件保留。

前一版已在 1440×900、390×667 和默认浏览器视口复核：显示器实体支架、手机平放与拿起、转头后的手持位置、拖动收回、人物侧面/背面及走道、金额选取编辑和保存、暂停。拖动装饰文字与手机后选中文本为空，金额输入框仍可 Ctrl+A；390×667 页面无横向或纵向溢出，运行日志无错误或警告。语法检查和静态构建通过。未重复整局浏览器通关，胜负和双路线由规则测试回归；浏览器指针检查不能代替真实触屏与性能验收。

本轮另在实际房间渲染中定格复核了坐姿办公、接水、转向房间饮水、回座前交谈、归桌继续工作；完整游戏中复核了金额保存、喝水、手机收放与转头跟随、静音、暂停，浏览器日志无错误或警告。音频文件全部完成解码、声源状态与声像检查，尚未做设备上的主观听感验收。

实体场景需要 WebGL2，不支持时会给出可见提示，不以平面背景平移冒充三维环顾。旧全景和二维人物素材保留为历史设计素材，已不作为运行时的环顾方案。手部仍有图片表现，饮水通过画面与声音反馈表达；音频混合本地实录片段和 Web Audio 底噪，无中文角色配音。尚未在真实手机上验证触摸手感、音频延迟与性能，也没有 B 站 SDK、广告、后端或原文档中的全部关卡。

早期工位、手持手机和人物图像由 imagegen 生成，提示记录保留在 [prompts.json](public/assets/prompts.json)、[phone-prompt.json](public/assets/phone-prompt.json) 与 [surround-prompts.json](public/assets/surround-prompts.json)。界面可选加载 Google Fonts，无法加载时使用系统字体回退；游戏必需的脚本、模型和图片均随构建产物提供。
