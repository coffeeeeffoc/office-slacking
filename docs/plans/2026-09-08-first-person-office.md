# 下班前的九十秒 Implementation Plan

**Goal:** 一个可独立运行、第一人称沉浸式操作的 H5 工位关卡。

**Architecture:** 连续时间游戏状态与界面分开；Three.js 实体办公室、骨骼人物与 CSS3D 电脑/手机共用相机和空间坐标。手机、电脑与回答分别保留证据；经理有可读预兆与固定巡查时刻。

**Tech Stack:** HTML/CSS/ES Modules、Three.js 0.180.0、Pointer Events、Web Audio、requestAnimationFrame；Node 内置测试与静态服务器。首次运行 `npm ci`，安装后脚本准备本地 vendor 模块，通过 import map 加载。浏览器需要 WebGL2，构建产物可直接由静态 HTTP 服务提供。

## 设计决定

用户已选择第一人称工位。以日光、办公软件、桌面杂物构成可信空间；用可操作的实物与场景内对白承载主要信息。先完成原设计第 05 关，不直接铺开 24 关。

90 秒内核对总数 128,600，休息满 20 秒，最终回到工作。手机拿起/放下保留过渡与中断；电脑娱乐页不随收手机关闭。靠近、驻足、离开均可预判，普通喝水不算违规。提供鼠标、触屏、键盘，拖放附点击替代；后台自动暂停。

连续环顾只改变观察方向，不改变证据、不暂停世界、不自动收手机；视线离开娱乐内容时停止相应休息计分。经理与小林的距离由场景地面坐标计算，点击距离按钮可以看向人物。

## 实现与验证

1. `src/game.js` 实现连续动作、可复现巡查时刻、证据、问答和胜负；`tests/game.test.js` 验证规则、暂停、时间步等价与安全通关。
2. `src/layout.js` 定义共享家具占地与通道，`src/space.js` 按全局游戏时间输出人物位置、朝向、速度和累计路程。路线沿通道绕开家具；停稳后渐变转身，再沿身体朝向迈步，起停保留加减速。`tests/space.test.js` 检查投影、距离、路线连续性、碰撞与原风险时刻不变。
3. `src/room.js` 构建实体地面、桌椅、柜子和光影。`src/people.js` 加载本地 CC0 Quaternius GLB 骨骼人物，依累计路程与实际模型步幅驱动行走，校正动画后的鞋底高度；`tests/people.test.js` 使用真实模型验证全身转向、接地、支撑脚滑移与暂停。
4. `src/desk.js` 与 `src/desk.css` 将电脑、手机等可操作界面作为 CSS3D 表面放置到实体底座，和场景使用同一相机。手机放下时贴桌，拿起后跟随视线；输入保留选取能力，装饰文字不会干扰拖动。`tests/desk.test.js` 验证收放、反向动作、随头转动和重建恢复。
5. `src/main.js` 与 `src/style.css` 保留可编辑表格、娱乐页、对白和按钮操作；`src/sound.js` 提供可关闭的环境与动作音效。模型许可及来源放在 `public/assets/models/LICENSE.md`。
6. 原实体工位版本通过19项回归；在 1440×900、390×667 和默认视口复核了桌面支撑、人物朝向/走道、手机收放与转头跟随、金额编辑保存、暂停与拖动不选文字。390×667 无页面溢出，运行日志无错误或警告。整局胜负由规则测试回归，未重复浏览器通关；真实手机手感与性能尚待设备验收。

## 修复背景与交付边界

早期环顾使用球面全景和二维人物图层。用户指出人物没有真实转身、移动像漂浮、走动区域不自然，因此本轮改为共用空间坐标的实体办公室与骨骼人物，旧全景和二维人物已不承担运行时环顾渲染。WebGL2 不可用时给出提示，不保留假平移回退。

当前为简化造型与材质的三维可玩样板，不能离开工位自由行走，不承诺照片级写实或完整人物表演。手部仍部分使用图片；CSS3D 表面与网格不支持通用逐像素深度遮挡，当前依靠正面布局和背面裁剪。动作声使用本地实录片段，空调与缺失片段以滤波噪声回退；交谈为模糊人声氛围，没有中文角色配音。真实手机的性能、触摸手感和音频延迟仍需设备验收；暂不接 B 站、账户、后端或通用关卡编辑器。

## 2026-09-09 办公室日常行为

补齐常驻同事和工位坐席，小林将打印、接水与短暂交流合并成一次离座，保留约一半游戏时间坐着工作。活动状态统一驱动骨骼、接触点、携带道具和空间音效。杯口改为空心几何，水面与杯壳分开，消除转头时的深度闪烁。声音默认在玩家点击开始后启用，随时可静音；本地音效署名位于 `public/assets/audio/LICENSE.md`。实际站姿、坐姿、手/杯/打印稿接触及声源的启停由Node回归和浏览器动作定格检查。
